# 暫定方針の妥当性レビュー（U-01〜U-22）

2026-09-24 実施。ROM 仕様が未公開のため暫定方針で実装していた項目（Issue #1〜#22、`U-xx` = Issue #xx）について、
公開資料との整合と、別解釈をとった場合の勝率への影響を調べた。

## 方針

**ROM 解析は行わない。** 各項目は本書の「採用」列の方針で確定扱いとし、Issue はクローズする。

- 公開資料で決められるものは、その資料に合わせて実装を直した（下表「修正」）。
- 公開資料では決めきれないものも、暫定方針のまま確定扱いにする（下表「据え置き（未決）」）。別解釈をとったときの影響の大きさは本書に残す。シミュレーション勝率を読むときは、これらの項目がある試合で数ポイントの誤差がありうることに注意する。
- コード中の `fidelityHits['U-xx']` は、近似した分岐を通った回数の記録として残す（Unknown の意味ではなく、本書の項目番号として読む）。

## 判定のしかた

- 資料: RetroGameHackers「DQ3戦闘部分解説」（RGH）とその補遺・小ネタ集、dqbook、Web 上の攻略・検証サイト（下記「出典」）。リメイク・FC 版・GB 版の資料は、使うときに明記した。
- 実測: エンジンを一時的に書き換えて別解釈を入れ、同じ試合を賭けた選手ごとに N 回（3,000〜40,000）回し、賭けた選手の勝率を比べた（主人公 Lv30）。seed だけを変えた場合のばらつきは、N=3,000 で最大 3pt 程度、N=10,000 で標準誤差 約 0.5pt。以下の「pt」は勝率の差（ポイント）。
- 判定の目安: 公開資料と矛盾せず、別解釈でも差が 1〜2pt 以内なら「適切」。

## 修正した項目

### U-07 混乱
- 「毎ターン開始時に 1/2 で回復」をやめ、戦闘終了まで続くようにした。
- 根拠: RGH 小ネタ集（SFC オリジナル版）は回復手段としてパーティアタック（7/8）だけを挙げる。gcgx（SFC ver1.0 の ROM を調査と明記）の回復方法は「パーティアタック」「戦闘終了」のみ。大辞典 wiki【混乱】DQ3 節も「自然に回復することはない」。
- 対象の選び方（自分以外の全選手から一様）と「混乱時通常攻撃化」は据え置き。資料と矛盾しない。
- 味方からの攻撃で解けるか（覚醒考慮）は下記 U-08 と同じ未決点で、実装しない。

### U-08 眠り・マヒ
- 眠り: 付与時は「1 回目の判定待ち」とし、自分の手番（行動枠 0）ごとに 1/8, 1/3, 1/2, 1 で起きる。起きたターンは行動が決まっていないので動けず、次のターンから動く（従来どおり）。
  - 根拠: RGH 小ネタ集「ラリホー中の覚醒判定は 1 回目 12.5%、2 回目 33.3%、3 回目 50%、4 回目 100%」。gcgx の状態異常表も同じ値。dqwiz「1〜4 ターン行動を封じる」。
  - 従来の「カウンター 1..3 を一様」は平均の判定回数が 2 回で、資料どおりの 2.75 回より短かった。実測で試合 32 バーナバス −6.2pt、試合 3 アルミラージ +4.3pt。
  - 乱数の引き方（1/8 = `rand0toA(7) === 0` など）は推測。
- マヒ: 戦闘中は回復しない（据え置き）。大辞典 wiki【麻痺】「戦闘中には絶対に自然回復しない」、gcgx の回復手段も キアリク・満月草・歩行 のみ。
- **未決**: 格闘場で味方からの攻撃により眠りが覚めるか。dqbook の覚醒考慮は「自陣側 → 自陣側」の条件で、全選手が敵陣側フラグ 0 の格闘場で成立するか公開資料では決まらない。攻撃では起きない方針で据え置き（7/8 で起きる解釈では試合 32 バーナバス +3.6pt、試合 3 アルミラージ −2.9pt）。

### U-11 同名コマンドの ID
- 従来は全モンスターに代表 ID（ホイミ 31 など）を当てていた。dqwiz「SFC/GBC モンスターの行動」が回復呪文を「（自分）」「（仲間）」と使い手ごとに区別しており、「自分」はコマンド表で対象陣営 1（自身）の変種 32/35/38 にだけ当てはまる。これに合わせて次を上書きした（`scripts/lib/commandNames.ts` の `MONSTER_COMMAND_OVERRIDES`）。
  - ホイミ → 32: わらいぶくろ、マージマタンゴ
  - べホイミ → 35: バーナバス、まほうおばば
  - べホマ → 38: エビルマージ
- 自身版の判断 j18/j19 は未実装で「無条件に選ぶ」に落ちていたため、j16/17 と同じ「HP が減っていれば選ぶ」として実装した。格闘場は 1 グループ 1 体なので、この組み合わせなら代表 ID のときと勝率は変わらない（実測で完全一致）。ID だけ替えると、満タンでも回復するようになり、マージマタンゴ −5.7pt などの差が出る。
- 据え置き: わらいぶくろのスクルト（dqwiz の「全」= ID 61）。格闘場で「全体」が誰を指すか決まらないため、代表 ID 58 のまま（61 を全員対象とした場合、試合 19 キャットフライの引き分け率 +6.5pt）。
- #23（召喚コマンド ID 96〜101、にげる = 106）は、格闘場では通常攻撃に置き換わり結果に影響しないため、推定のまま確定扱い。

### U-13 耐性ロール
- 耐性 1 の成功閾値を 192 → 180（/256、約 70%）にした。RGH-MOD-011 本文と gcgx が 70% としており（RGH-025 の表だけ 75%）、耐性 2 の 76 と対称な 256 − 76 を採った（値は推測）。影響は試合 27・29 で 2.3pt。
- 耐性 0/2/3 と、眠り・毒・マヒ攻撃の固定成功率（37.5/25/12.5%）は据え置き。
- **未決**: 系統 0 の息（あまいいき・やけつくいき）のモンスター相手の成功率。RGH-025 はモンスター側を「—」、dqbook は成功率係数のみ。据え置き（成功率係数 / 8）。必ず成功とする解釈では試合 32 バーナバス −25pt、試合 11・34 で 9pt と、影響は今回の項目で最大。

### U-14 能力変化
- ルカナン: 現在の守備力の 1/2 を下げる（`def -= floor(def / 2)`）。gcgx・dqwiz・d-navi がそろって「現在守備力の 50%」。従来は素の守備力の 1/2。
- ボミオス: 素早さを 0 にする。gcgx・dqwiz・大辞典 wiki がそろって「元の素早さの 100% を下げる」。従来は素の素早さの 1/2。
- スクルト（素の守備力の 1/2 を加算）、マホトラ・ふしぎなおどり（5〜10）は据え置き。資料と一致する。
- 影響: 試合 25 マリンスライム −7.4pt、マーマン +4.8pt（スクルトで上げた守備をルカナンが大きく削るため）。

### U-18 オッズの境界処理（記録の修正のみ）
- 挙動（`odds10 = max(10B + v, 10)`）は据え置き。dqwiz の範囲表（B=4 → 3.7〜4.3 など）と RP2nd の実測（GB 版。B=1 → 1.0〜1.3、平均 1.06）が、v < 0 を 10B + v とし下限 1.0 に丸める解釈と一致する。符号を落とす解釈は下限 3.7 の観測で否定される。
- `fidelityHits['odds-negative-boundary']` を v < 0 のたびではなく、下限 1.0 に丸めたときだけ数えるようにした。丸めが効くのは B=1 の選手だけ。

### U-20 払い戻しと引き分けの返金
- 当たりの払い戻し = 賭け金 × オッズ（賭け金込みの総額）は据え置き。RP2nd の期待値計算（勝率 × 平均倍率 ＋ 引分率）と整合する。
- 引き分けは、賭けた選手が生き残った引き分け（10 ターン経過、`reason: 'turn-limit'`）だけ返金し、生存 0 体の引き分け（`'all-inactive'`）は没収にした。
  - 根拠: 大辞典 wiki（SFC 版以降）「引き分けの場合は自分が賭けたモンスターが生き残っている場合のみゴールドが返還される」。gcgx・RP2nd も同旨。dqwiz「SFC 版ではメガンテは引き分けになってしまうので、ばくだんいわには賭けるだけ無駄」も、自爆で生存 0 体なら返金されないという読みと合う。
  - 影響は試合 31 に集中する（ひとくいばこの期待値 1.63 → 1.28、ばくだんいわ 0.36 → 0.02）。各試合で期待値が最大になる選手は変わらない。
- 設定の「没収」（引き分けは常に没収）は比較用に残した。
- 所持金の上限と、券を複数枚買えるかは資料がなく、扱わない。

## 据え置いた項目

### 公開資料と整合し、影響も小さいもの

- **U-01 候補列挙**: Group 4 を特別扱いしない。RGH-003 は Group 4 の用途をメッセージ表示などと説明しており、対象選択には触れない。Group 0-3 が Group 4 だけを狙う解釈では、試合 6 おばけありくいの勝率が 75.6% → 0% になるなど、本命に賭けて勝てる実態と矛盾する。
- **U-02 狙い直し**: dqbook「空振り時対象再抽選考慮」の定義どおり。フラグ 0 の呪文も選び直す解釈で最大 1.2pt。
- **U-03 集中攻撃の記憶**: RGH-012・小ネタ集「死ぬか離脱するまで攻撃し続ける」と一致。眠り・マヒも外す解釈で 0.3pt 以下。
- **U-05 神のタイミング**: RGH-011-2「自分の行動時点まで行動決定しない」。格闘場の神 18 種は全員 1 回行動で、防御を持つのはキャットフライだけなので、未解明の細部はほぼ効かない。ターン開始時に決める極端な解釈でも 1.4pt。
- **U-09 初期 HP**: RGH-005 で、格闘場の出場者も通常戦と同じ初期化経路（`$025AC7` → `$02AB00` → `$02ABA1` → `$02ABAE`）を通り、`$02ABA1` の分岐に格闘場フラグは無い。なお「格闘場では最大 HP 固定」とする解釈は影響が大きい（試合 31 ひとくいばこ −18pt）が、それを支える資料は無い。
- **U-10 あやしいかげ**: gcgx（SFC ROM 調査）「正体（ステータス・行動）は別のモンスター」、大辞典 wiki「行動は正体に準じます」、dqwiz「個々の正体は別々」。能力値だけあやしいかげ自身から取る解釈では引き分け率が 69〜85% に跳ね上がるが、資料と合わない。
- **U-12 みかわしの分子**: dqbook は「+1 を 48 で割った値と考えられる」、gcgx は +1 しない値。どちらでも最大 2pt（試合 14）。
- **U-16 乱数**: SFC 版 DQ3 の乱数の中身を記した公開資料は無い。用途は勝率分布の推定なので、分布が等価な擬似乱数で足りる。質の悪い乱数（16bit LCG）に替えても差は誤差の範囲（最大 1.1pt）。実機の乱数列との一致は目標にしない。
- **U-17 レベル帯**: dqwiz・ドラクエ３攻略プロジェクト・RP2nd（GB 版の実測）の試合数（10/19/24/33/38）が半開区間 [0, 値) の解釈と一致する。
- **U-19 予想屋**: gcgx「完全にランダムで決まるので、まったく参考にならない」、大辞典 wiki も同旨。戦闘・オッズに影響しない。予想屋は未実装で、実装するなら「出場選手から一様に 1 体」でよい。
- **U-21 中断処理・行動可否**: gcgx「試合中 B ボタンを押しっぱなしにしていると、試合途中で帰ることができる」から、`$027329` は B ボタンによる中断の判定と見られる（推測）。シミュレーターは中断しない前提なので「常に c=off」でよい。`$0273B3` の条件は PC 側の類似ルーチン `$025E63`（RGH-007）と一致する。
- **U-22 インデックス**: 逆順にしても最大 0.9pt（同名 4 体の試合 5 でも 0.6pt）。
