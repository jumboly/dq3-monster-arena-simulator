### 2.3 オッズ計算 【Likely（中間生成値の範囲）/ Unknown（境界処理）】

出場選手ごとに、オッズ属性値 `B`（1..255）から中間生成値 `v` を作る（dqbook-matchmake 表 `$C3EDBB`）:

| B | v |
|---|---|
| 1..5 | `randint(0, 6) - 3`（-3..+3） |
| 6..10 | `randint(0, 14) - 7`（-7..+7） |
| 11..30 | `randint(0, 40) - 20`（-20..+20） |
| 31..100 | `randint(0, 100) - 50`（-50..+50） |
| 101..255 | `randint(0, 200) - 100`（-100..+100） |

（`randint(a,b)` は閉区間。dqbook の表記に従う。）

`Q, R` = `v` と 10 の商と余り。**v ≥ 0 のとき**: 整数部 = `B + Q`、小数部 = `R`。【Likely】（dqbook の文言そのもの）

境界処理（dqbook: 「中間生成値が負であったり、剰余が 0 であったり、属性値と商との和がゼロ以下になるような場合についても適宜対処している」）は**中身が未公開**。【Unknown】→ U-18

暫定実装（Approximation。`fidelityHits['odds-negative-boundary']` を計上）:
```
odds10 = 10 * B + v                      // 小数 1 桁を整数で持つ（Odds{integer, tenths} と等価）
if odds10 < 10: odds10 = 10              // 「和がゼロ以下」対策の暫定。実機の下限は未確認
integer = floor(odds10 / 10); tenths = odds10 % 10
```
- 「v が負」の扱いは、数学的に自然な `10B + v` を採る（例: B=4, v=-3 → 3.7）。実機が `B - |Q|` と `|R|` を別々に扱う（例: 4 - 0 . 3 → 4.3 と誤る/意図的にそうする）可能性を排除できないため Unknown。
- 「剰余が 0」の特別扱いが何を意味するか（小数部 0 の表示?）も不明。
- 1 回の入場で各選手 1 回ずつ抽選すると考える。【Likely】
- 属性値 0（空き枠）の選手は出場しない。

### 2.4 予想屋 `$C3EFBE` 【Likely（料金・流れ）/ Unknown（予想の決め方）】 出典: dqbook-matchmake

- 予想内容はマッチメイク時点で「出場選手数と乱数」で決定済み。
- 予想代は一律 5 ゴールド。聞かない場合と所持金 5G 未満の場合は同じ処理。
- 予想が当たる確率・選び方（オッズとの関係、ランダム一様か）は未公開。【Unknown】→ U-19。暫定: 出場選手から一様ランダムに 1 体を「予想」とし、戦闘結果とは独立（Approximation）。

## 5. あやしいかげ（試合 38）の実体決定（Phase B 用）

戦闘側（`$025AC7` → `$025B46`）で決まる。詳細は `battle-spec.md` §2.4。【Confirmed】 出典: RGH-005, RGH-TRIVIA

```
L = 隊列先頭キャラクターのレベル                 // 主人公レベルではない点に注意
candidates = [ id for id in #$83..#$01 if monster[id].level <= L ]
各あやしいかげごとに独立に: entity = candidates[ rand0toA(len-1) ]   // 3 体それぞれ別の実体になりうる
```
- 3 体とも同じ ID `#$19` なので、`$025AC7` の出現数ループ内で `$025B46` は**グループ単位で 1 回**呼ばれる（`JSR $5B46` はループ `$025B0A` の外側）。格闘場では 3 体が別グループ（出現数 1 ずつ）と推定されるので、**結果的に 3 体それぞれ独立に抽選**。【Confirmed（呼び出し位置）/ Likely（格闘場で 3 グループであること）】
- 候補に あやしいかげ自身（Lv10）とボス（キングヒドラ、ボストロール、やまたのおろち等）を含む。RGH-TRIVIA: Lv38 以上でボストロール、Lv46 以上でキングヒドラ、Lv63 以上でやまたのおろち（1,2 共に）が実体になりうる。
- オッズ属性 7（B=6..10 の帯なので v ∈ -7..+7）で、実体に関係なくオッズは決まる（マッチメイク時点では実体未決定）。【Likely】
- 実体のどの属性（HP、コマンド、耐性、行動パターン、みかわし）が戦闘に使われるかは未確認 → U-10。
